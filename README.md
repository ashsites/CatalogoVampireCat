# Catálogo de Accesorios – Vampire Cat

Sitio web estático que muestra el catálogo de accesorios de Vampire Cat, con lazos, vinchas, prensas y pulseras. El visitante puede navegar por categoría, buscar por color, diseño o tema, y ver cada producto con su foto, nombre y precio en colones.

Está hecho con HTML, CSS y JavaScript puro, sin dependencias ni proceso de compilación, así que funciona abriéndolo directamente en el navegador o publicándolo en cualquier hosting estático como GitHub Pages. Se adapta a celulares y los pedidos se coordinan por mensaje en Instagram o Facebook.

Los productos, sus precios y los enlaces a redes sociales se definen en una sola lista al inicio del código, y las tarjetas del catálogo se generan automáticamente a partir de ella, por lo que agregar o quitar productos no requiere tocar el diseño.
